04 / REPLAY & LIVE

兩種執行模式，同一條決策路徑

replay 與 live 各自負責取得時間序列與輸出，預測與決策都走 make_frames。

原始碼：replay.py、live.py、notify.py
01 / SHARED PATH

共用路徑：make_frames

evaluate 的分流模擬、replay、live 都走同一條路徑，所以評估數字、儀表板重播和即時輸出的決策規則完全一致。

build_features → predict_from_features (車速) ─┐ predict_proba_from_features (壅塞機率) ─┴→ Lookup → make_frames → diversion.decide
  • Lookup(feats, preds, probs, thresholds) 把輸出轉成 (ts × 18 路段) 寬表：actual（speed_lag0）、volume（volume_lag0）、pred[h]、prob[h]、各時距門檻。
  • make_frames 對每個時間點產生一個 frame，並維護冷卻狀態：決策 push 為真時更新 last_push。
02 / FRAME JSON

frame 格式

欄位說明
tsYYYY-MM-DDTHH:MM，預測起點時刻
actual{seg_id: 當下實際車速或 null}，小數 1 位
pred{"15"|"30"|"60": {seg_id: t+h 預測車速或 null}}
route_tt.actual／.pred30各路線旅行時間（整數秒）：以實際車速／+30 預測車速估算
decisionDecision.to_dict()：push、reason、slow、fast、saving_naive_s、p_star、saving_quota_s、alt_tt_*、message、stay_message、tt_*、sys_saving_*
prob{"15"|"30"|"60": {seg_id: 壅塞機率或 null}}，小數 2 位
alarm{"15"|"30"|"60": [seg_id…]}：prob ≥ 該時距門檻 且當下實際車速 ≥ 40（已壅塞或缺值者不列入）
03 / REPLAY & LIVE

兩種執行模式

模式資料怎麼來每個時間點做什麼輸出
Replay
fcf replay		讀 corridor.parquet，取 [start − 1 小時, end]（多 1 小時供 lag）只對 [start, end]（預設 06:00–10:00）產生 frame；冷卻狀態從當日起點重新開始dashboard/data/replay-YYYYMMDD.json，並更新 index.json
Live
fcf live		列目錄找最新 M05A 檔；冷啟動往回抓 7 個時點，之後只補新檔；單一時點 HTTP 錯誤只記錄保留最近 7 個時點（WINDOW）做特徵與預測；frames 只保留最後 12 個dashboard/data/live.json（不進版控）
  • live 迴圈每 --poll 秒（預設 120）檢查一次；迴圈內任何例外只記錄 error: ...，下個週期重試。時區 Asia/Taipei。
  • 載入一次：模型、分類器、profile、capacity 在迴圈外載入。
  • find-events：挑 TEST 內分流效益最大的上班日（以實際車速估算的 平面 TT − 高架 TT 最大值排序），只印出表格。
# 歷史案例 uv run fcf find-events --top 5 uv run fcf replay --date 2026-09-03 # 即時（加 --push 才呼叫 LINE） uv run fcf live --poll 120 uv run fcf live --poll 120 --push
04 / LINE

LINE 推播：notify.py

  • 缺 LINE_CHANNEL_ACCESS_TOKEN 或 LINE_USER_ID 任一 → dry-run，只印出 [DRY-RUN] LINE -> ...。
  • 否則 POST https://api.line.me/v2/bot/message/push；非 200 或 HTTPError 丟 RuntimeError。
  • live --push 只在最新 frame 的 decision.push 為真時送出 decision.message；prob／alarm 與 stay_message 都不推播。
資料延遲：replay 以資料時間戳為「現在」，沒有模擬檔案發布延遲（實測約 5–7 分鐘），實際可用提前量會相應縮短。
