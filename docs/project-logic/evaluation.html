01 / SETUP

怎麼評估

  • 只評估 TEST（2026-08-01 ～ 09-06）；為了讓第一天有足夠的 lag，載入時多帶前一天，指標只統計 ts 落在 TEST 內的列。
  • 子集 all：全部；am_peak：上班日且 06:00 ≤ 預測起點時刻 < 10:00。
  • 基準線：持續法（t+h 車速 = 現在車速）與歷史平均（profile_speed）。
  • 壅塞定義：車速 < 40 km/h。

04 / ONSET LEAD

壅塞起點提前量

  1. 起點 oactual[o] < 40，且前 3 步（15 分鐘）都 ≥ 40。
  2. 掃描 t從 o 之前 60 分鐘到 5 分鐘，逐一檢查；t 當下車速須 ≥ 40。
  3. 命中存在時距 h 使 t+h 落在 o ± 10 分鐘，且該方法在 t 對 h 發出預警（回歸：pred_h < 40；分類器：prob_h ≥ 門檻）。
  4. 提前量取最早命中的 t：提前量 = o − t（分鐘）；都沒命中為「未偵測」。
